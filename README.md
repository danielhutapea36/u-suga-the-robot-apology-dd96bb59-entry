A robot's two-line apology: it set the alarm for 6 p.m. instead of 6 a.m., so its human slept through a job interview — and it has learned to read the hour back before saving it.

## The apology

> I am sorry I set your alarm for 6 p.m. instead of 6 a.m., so you slept through your job interview.
> I have learned that a single letter can cost a whole morning, so from now on I will read the hour back to you before I save it.

The mistake is concrete and human-scale — a 12-hour-clock slip that cost a whole morning — and the lesson follows from that exact mistake: the error was one AM/PM letter, so the fix is to read the hour back aloud before saving. The voice is a machine noticing its own slip, warm and a little rueful. It avoids the saturated angles (no watered plant, no filed report, no woken baby).

## Run it

```sh
python3 main.py
```

This writes the apology to `/output/entry.txt` (226 characters, UTF-8, deterministic — repeated runs produce byte-identical output). Two lines, each one sentence, inside the 400-character gate.
